# 课隙 · 本地切片学习台

给基金从业长课用的本地学习工具：打开本地视频或导入 B 站缓存课程，自动生成字幕，再按知识点和段落切成学习单元，逐段播放、标记、记笔记并导出 Markdown。

视频不上传云端，语音识别在本机完成。切片和笔记会自动保存到 `D:\课隙`（没有 D 盘时保存到“文档\课隙”），同时浏览器 IndexedDB 保留一份工作副本。

完整的开发过程、架构决策和踩坑记录见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 给同学：免安装便携版

如果对方电脑没有 Node.js / Python，也不想运行安装程序，使用 `kexi-portable-v0.1.2.zip`：

**直接下载**：[GitHub Releases · 课隙 v0.1.2 便携版](https://github.com/MJK0412/kexi-study-desk/releases/tag/v0.1.2)

1. 解压整个 `kexi-portable` 文件夹到任意位置（不要在压缩包里直接双击）。
2. 双击 `start-kexi.vbs`，等待 5–15 秒，浏览器会自动打开。
3. 想放桌面，双击 `create-shortcut.vbs`。
4. 首次自动转写会下载约 480MB 模型；之后可离线使用。

v0.1.1 已修复启动器在非 UTF-8 Windows 上的 `0x800A0408 无效字符` 错误，并把顶层文件名改成英文，避免中文 ZIP 乱码。v0.1.2 进一步把新转写和旧课程字幕统一转换为简体中文；旧课程第一次打开时自动转换，笔记保持不变。便携版自带 Node、Python 和语音依赖，不需要管理员权限，也不会触发 Smart App Control 拦截。不要把 `start-kexi.vbs` 单独移出文件夹。

## 直接使用（推荐）

桌面上有一个 **「课隙」** 图标：

1. 双击「课隙」。
2. 浏览器会自动打开学习台。
3. 点「打开视频」，选择本地课程视频；或点「B 站缓存」导入已缓存的课程。
4. 点「自动转写」，等待本机生成字幕。
5. 完成后自动生成切片，点「开始学习」。

不需要开 PowerShell，不需要自己准备 SRT。

桌面图标使用课隙自己的深绿色图标，由 `课隙.vbs` 在后台启动服务并打开浏览器。如果快捷方式被删掉，也可以直接双击 `课隙.vbs`。启动服务会隐藏在后台，只打开浏览器。

> 第一次使用会在后台下载约 480MB 的语音模型。下载完成后可离线使用。模型缓存在 `server/models/`。

## 第一次启动没反应？

- 启动器会先等服务就绪再打开浏览器，通常需要 3–5 秒；如果服务没起来，会弹出提示而不是静默失败。
- 如果提示本地转写服务未启动，确认是通过桌面图标或 `课隙.vbs` 启动，而不是直接双击 `index.html`。
- 查看启动日志：`server/launcher.log`；服务日志：`server/app.log`。
- 如果语音组件丢失，在项目目录执行一次：

```powershell
npm run setup:asr
```

## 自动转写怎么工作

- 语音识别引擎：`faster-whisper`，模型 `small`，CPU int8。
- 视频先写入本地临时文件，由本机 Python 进程读取音轨并识别。
- 长视频按 10 分钟分块识别，降低内存占用。
- 完成后临时视频立即删除，识别结果写入 IndexedDB。
- 识别中可取消；重新转写或更新字幕后，会按新内容重新切片，并尽量把原有标签、笔记和倍速跟随到对应内容。
- 本地视频本身不持久化，刷新页面后需要重新连接原文件；B 站缓存课程会在刷新后自动恢复。

> 10 分钟视频通常需要几分钟，具体取决于 CPU。长课程建议接通电源。

## B 站缓存课程

B 站桌面端缓存把视频、音频分开存成两个 `.m4s` 文件。课隙会在本地把它们合并成一个可拖动的 MP4，再播放或转写。

- **直接读取**：缓存位于 `C:\Users\<你的用户名>\Videos\bilibili` 时，点顶部「B 站缓存」，列表会自动出现课程；也可以用环境变量 `KEXI_BILIBILI_ROOT` 指定其他位置。
- **手动上传**：点「选择缓存文件夹」选中某一讲缓存目录；或点「选择 .m4s 文件」，同时选中视频轨和音频轨（音频轨通常是 `-30280.m4s`）。
- 合并后的播放文件缓存在 `server/bilibili-cache/`，B 站课程刷新后会自动重连，不需要重新选文件。
- 如果只上传 `.m4s`、没有带 `videoInfo.json`，课程标题会先用文件名；想保留原标题时建议直接选择缓存文件夹。
- 缓存文件仍只在本机服务内处理，不上传云端。

## 保存位置：D:\课隙

每门课在 `D:\课隙` 下有一个以课程名命名的文件夹：

```text
D:\课隙\
└─ 1.1-随机事件\
   ├─ 切片 01 · 00-00 至 01-00 · 已掌握.md
   ├─ 切片 02 · 01-00 至 02-00 · 待回看.md
   ├─ ……
   ├─ 课程总览.md
   └─ 课程数据.json
```

- `切片 NN · 时间 · 标签.md`：每个学习切片一个文件，包含时间范围、标签、该段字幕原文和笔记，可以直接打开阅读或继续补充。
- `课程总览.md`：整门课的目录和全部切片内容，适合从头复习。
- `课程数据.json`：完整数据备份，包含课程信息、字幕、切片、标签、笔记和倍速。

新增课程、重新转写、修改标签、修改笔记或倍速后，文件夹内容会自动更新；重新切片时，旧的切片文件会被清理，避免留下过期笔记。右上角的文件夹图标和页面底部「自动保存至 D:\课隙」都可以直接打开这个目录。

课程名里不能用作文件名的符号会自动替换成下划线；如果两门课同名，第二门会保存到 `课程名 (2)` 文件夹。删除浏览器课程不会自动删除 D 盘存档，避免误删学习记录。

## 按内容切片

不再按固定 60 秒切分。字幕生成后，本地规则会按讲解逻辑寻找边界：

- 「第一个知识点」「接下来我们看」「什么叫……」「此处注意」等知识点转折；
- 段落停顿、句末收束和长段落的自然断点；
- 至少 20 秒，避免切成碎句；最长 180 秒，防止一个知识点过长。

切片会尽量保持一段完整讲解，不会把一句话从中间切断。更新字幕或重新转写后，旧切片上的标签、笔记和倍速会尽量跟随到对应内容。

## 没有自动转写时

仍支持导入已有字幕：`.srt` / `.vtt`。适合你已经有字幕、或者想先快速体验的情况。

## 学习操作

- 左侧切片：点击跳转；按「全部 / 待回看 / 重难点 / 已掌握」筛选。
- 播放区：逐段模式到本段末尾自动暂停；连续模式不暂停。
- 每段独立倍速、标签、笔记。
- 聚焦笔记输入框时自动暂停视频（可关闭）。
- 快捷键：`Space` 播放/暂停，`←` `→` 前后 5 秒，`N` 下一段，`P` 上一段。
- 右上角「导出」下载 Markdown 学习笔记。

## 数据与隐私

- 语音识别在本机 CPU 运行，视频只到本地 `127.0.0.1` 服务。
- 临时视频存放在 `server/tmp/`，任务结束或取消后删除。
- 课程、字幕、切片、标签、笔记会自动保存到 `D:\课隙\<课程名>\`，每个切片一个 `.md`，另有课程总览和 JSON 备份。
- 浏览器 IndexedDB（`kexi-study-desk`）保留工作副本，负责页面内的快速读取。
- 视频文件只在当前页面会话内；本地视频刷新后需重新选择，B 站缓存课程会自动重连。
- D 盘存档是独立的可读文件；即使清除浏览器数据，切片 `.md` 仍可阅读，`课程数据.json` 仍保留完整内容。
- 仅处理你合法拥有的课程文件，不抓取、不破解网课平台。

## 另一台电脑上使用

GitHub 仓库里是源代码，不是已经装好环境的安装包。别人要在自己的 Windows 电脑上使用，需要先装：

- Node.js 20.19+ 或 22 LTS；
- Python 3.10+；
- Git（也可以直接下载仓库 ZIP，但后续更新不方便）；
- Chrome 或 Edge。

然后在项目目录执行：

```powershell
npm install
npm run setup:asr
npm run dev
```

第一次点「自动转写」时还会下载约 480MB 的 `small` 模型。之后可以双击 `课隙.vbs` 启动；如果 Node 不在默认路径，启动器会尝试 PATH 里的 `node`。

注意：

- 视频、B 站缓存、模型、`server/.venv`、`D:\课隙` 学习记录都**不在仓库里**，每个人用自己的文件；
- 课程存档默认写到 `D:\课隙`，没有 D 盘时可以设置环境变量 `KEXI_ARCHIVE_ROOT` 指向别的目录；
- GitHub Pages 只能托管静态页面，无法提供本地语音识别、B 站缓存合并和 D 盘存档，所以不能只靠一个网页链接使用。

如果要让完全不懂技术的人“下载即用”，需要另外做 Windows 安装包，把 Node、Python 和模型一起打包；当前仓库还没有做到这一步。

## 为什么需要一个本地服务

浏览器不能直接运行完整的 Whisper 模型来稳定处理长课程：模型体积大、CPU 占用高，而且需要解码视频音轨。课隙用一个只在 `127.0.0.1` 监听的本地服务完成识别，网页仍然是普通浏览器页面，但不需要你手动开终端。

如果以后要分享给别人，让对方拉取代码后执行一次 `npm install` + `npm run setup:asr`。不要直接复制 `server/.venv`，虚拟环境里是当前电脑的绝对路径；模型也会在首次转写时重新下载。

## 已知限制

- 当前主要面向 Windows + Chrome / Edge。
- 识别速度依赖 CPU；没有 GPU 加速。
- 没有说话人分离、字幕润色、全文检索；切片使用本地规则，不调用云端 LLM。
- 本地视频刷新后需重新连接原文件；B 站缓存课程不需要。
- 模型精度受背景音、口音和录音质量影响。
